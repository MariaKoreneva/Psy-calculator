# Калькулятор времени психолога

Статический сайт, который помогает психологу увидеть, куда уходят 24 часа, сколько времени реально остаётся и сколько можно выделить на продвижение практики.

Данные хранятся только в браузере (`localStorage`). Сервер и регистрация не нужны.

## Что внутри

- Приветственная главная страница
- Калькулятор дня: сон, работа, консультации, дом, свои дела
- Цель по времени на продвижение
- Круговая диаграмма, топ крупных блоков, подсказка «где освободить время»
- История сохранённых дней и график динамики

## Как открыть

Откройте в браузере файл `index.html`.

Либо поднимите локальный сервер из папки проекта:

```bash
python -m http.server 8080
```

Затем зайдите на [http://localhost:8080](http://localhost:8080).

## Структура

```
index.html          главная
calculator.html     калькулятор
css/styles.css      стили
js/app.js           логика калькулятора
assets/             иконка и служебные файлы
```

## Приватность

История дней не уходит в интернет. Если очистить данные сайта в браузере, сохранённые дни пропадут.
